Add ReLU bitmask epilogues to `wp.gemm()`: `activation="relu"` with `aux` stores a bitmask of the positive pre-activations (a `uint8` array of shape `wp.gemm_relu_mask_shape(M, N)`) and `grad_aux` applies it in the backward GEMM (cuBLASLt `RELU_AUX`/`DRELU`, optionally with the bias gradient), so a ReLU layer's backward pass needs no separate masking kernel. The built-in kernel path supports the same layout.
