`wp.gemm()` now keeps cuBLASLt inside API captures (`apic=True`): the call is recorded as a semantic GEMM operation, so live API-captured graphs run cuBLASLt and saved graphs re-plan the GEMM with the cuBLASLt available where they are loaded (format version 20). Without cuBLASLt, CUDA GEMMs use a built-in tiled GEMM compiled into `warp.so`, and CPU GEMMs use the BLAS library NumPy ships with (OpenBLAS or Accelerate) or a built-in AVX-512/AVX2-dispatched blocked GEMM, replacing the generic Warp kernel. `WARP_CUBLASLT_PATH=none` disables cuBLASLt and `WARP_GEMM_HOST_BLAS=0` disables the host BLAS.
