In CUDA tile blocks of at most one warp (`block_dim <= 32`), `wp.tile_extract()` now reads register tiles with warp shuffles instead of copying them to shared memory, and full-warp `wp.tile_sum()`/`wp.tile_max()`/`wp.tile_min()`/`wp.tile_reduce()` use an xor butterfly that needs no ballot. The common `wp.tile_extract(wp.tile_sum(wp.tile(x)), 0)` reduction of per-thread values runs about 1.9x faster in such blocks, with no shared memory or block barriers.
